#  CleverNote

##  Problemática que resuelve
Los estudiantes y profesionales técnicos suelen utilizar múltiples herramientas inconexas para escribir, previsualizar y organizar documentos en formatos específicos (Markdown, LaTeX, HTML y TXT). Esto genera desorden en la información y una baja en la productividad al no contar con un entorno centralizado que unifique la autenticación, la gestión, el almacenamiento seguro y la lectura ágil de estos distintos tipos de archivos en una sola plataforma.

---

##  Módulos Principales del Sistema

* **Módulo de Usuarios:** Gestión de credenciales, perfiles y autenticación (Login/Register).
* **Módulo de Documentos (Notas):** Núcleo central para el CRUD de archivos, manejando el contenido, las extensiones (`.md`, `.latex`, `.txt`, `.html`) y la vinculación con APIs.
* **Módulo de Almacenes:** Sistema de agrupación lógica (carpetas o categorías) para organizar el entorno de trabajo del usuario.
* **Módulo de Seguimiento de Tareas:** Tablero interactivo para gestionar el estado de los proyectos o documentos (*Pendiente*, *En proceso*, *Completado*).
* **Módulo de Configuración y Filtros:** Motor de búsqueda dinámica y paginación para consultar de manera eficiente grandes volúmenes de documentos.

---

## Roles de Usuario

* **Administrador:** Acceso total para supervisión del sistema, control de usuarios y visualización global de métricas.
* **Usuario Estándar:** Capacidad para iniciar sesión, gestionar su propio perfil, crear almacenes y realizar operaciones CRUD completas sobre sus documentos.
